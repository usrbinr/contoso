Getting started

contoso gives you the same retail dataset in two ways: as tables bundled with the package, and as larger cloud versions you query through ‘DuckDB’.

Bundled tables

Loading the package makes eight tables available: sales, orders, orderrows, customer, product, store, fx and calendar. They need no download or connection.

library(contoso)

Larger datasets in ‘DuckDB’

create_contoso_duckdb() streams the Parquet files from cloud storage into an in-memory ‘DuckDB’ database. Pick a size by the number of sales rows:

size sales rows
"small" 7,794
"medium" 2,349,091
"large" 23,719,935
"mega" 237,245,485

"small" is the same data as the bundled tables. The other sizes cover a different date range and a much larger customer catalogue.

db <- create_contoso_duckdb(size = "medium")

The result is a list with one lazy table per dataset and the connection, db$con. Write dplyr as usual; it runs in ‘DuckDB’ until you collect():

db$sales |>
  dplyr::summarise(net_revenue = sum(net_revenue), .by = currency_code) |>
  dplyr::collect()

Use launch_ui() to browse every table in the ‘DuckDB’ UI, and disconnect when you are done:

launch_ui(db$con)

DBI::dbDisconnect(db$con, shutdown = TRUE)

Data dictionary

Every table and column is described in a data-dict file, with keys, joins and the formulas behind each measure:

system.file("extdata", "small", "data-dict.yaml", package = "contoso")

Use "cloud" in place of "small" for the dictionary of the larger sizes.
